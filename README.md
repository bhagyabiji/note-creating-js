# Notes App 

A simple and user-friendly Notes App built using HTML, CSS, and JavaScript. It allows users to create, edit, search, and delete notes easily.

The application uses browser Local Storage to save notes, so they remain available even after refreshing the page.

##  Features

- Create new notes with a title and description.
- Edit existing notes.
- Delete unwanted notes.
- Search notes by title or content.
- Display the date and time of the latest update.
- Store notes using Local Storage.
- Retain saved notes after browser refresh.
- Validate empty input field.
