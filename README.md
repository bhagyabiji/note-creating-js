# Notes App 

A simple and user-friendly Notes App built using HTML, CSS, and JavaScript. It allows users to create, edit, search, and delete notes easily.

The application uses browser Local Storage to save notes, so they remain available even after refreshing the page.

##  Features

- Create new notes with a title and description.
- Edit existing notes.
- Delete unwanted notes.
- Search notes by title or content.
- Display the date and time of the latest update.
- Store notes using Local Storage.
- Retain saved notes after browser refresh.
- Validate empty input field.

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

##  How to Run the Project

No additional software or package installation is required.

1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application will open in your default web browser.


##  How to Use

1. Enter a title for your note.
2. Write your note content.
3. Click the **Add Note** button.
4. Click **Edit** to modify an existing note.
5. Click **Delete** to remove a note.
6. Use the search bar to find notes by title or content.
